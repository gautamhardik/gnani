# Audio test recordings

The pack includes 30 spoken-order test prompts and a recording manifest, but deliberately does not include fabricated recordings. Record each prompt as a separate WAV file (mono preferred; 16 kHz or 24 kHz PCM is convenient) using a real consenting speaker. Keep the recording natural; include some code-switching and normal pauses. Avoid recording phone numbers, addresses, or other personal data.

Save files as `TC001.wav` through `TC030.wav` in this folder. Keep audio turns short (ideally 3–15 seconds; confirm the current Prisma endpoint limit in the docs). Add speaker IDs that are pseudonymous, not real names, in any private evaluation notes. Do not upload anyone's voice without their permission.
